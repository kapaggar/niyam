## Implementation notes

- Pinned API implemented exactly. `readyFile` derives the subdir from
  `relativePath`'s directory part (falls back to flat `ready/<filename>`
  when there is none); `encryptedFile` uses the full `relativePath`.
- `observe` hashes and sniffs in a single streaming pass (64 KiB buffer).
  Sniff order: ID3 → MPEG sync (0xFF / 0xE0 mask) → `Salted__` → `<` HTML →
  empty → OTHER. The sniff is a small private duplicate of A2's
  `Integrity.sniff` by design (A2 may not exist during wave A); commented
  in-source for the Lead to unify later.
- Index: `{root}/.state/index.json`, kotlinx.serialization JSON,
  `Map<canonicalPath, {size, mtime, sha256}>`. Corrupt/missing = empty,
  never throws; persisted after each record/invalidate; all access behind a
  private lock. Cache hits re-sniff only the first 16 bytes (the index
  stores no magic, per the pinned entry shape).
- `atomicMove`: mkdirs target parent, `Files.move(ATOMIC_MOVE)`, fallback
  `REPLACE_EXISTING` on `AtomicMoveNotSupportedException`. It also drops
  index entries for both paths — not in the pinned signature, but a moved
  file preserves mtime, so a stale (size, mtime) hit at the destination
  would otherwise serve the wrong hash.
- `cleanupOrphans` deletes only `*.partial` / `*.dec.partial` in `tmp/` and
  anything in `tmp/quarantine/` older than `maxAgeMs`; other tmp files are
  untouched (tested).
- `StorageLocator.scan`: depth ≤ 2, first hit per filename in roots order,
  deterministic (sorted listings). A dir named exactly `common-general` at
  depth 1 or 2 short-circuits the root to a flat listing of that dir only.
  Symlinks escaping the root are rejected by canonical-path prefix check;
  unreadable/missing roots skipped silently (`listFiles() == null`).

## Deviations / notes for the Lead

1. `atomicMove` invalidates the index for `from` and `to` (rationale above).
2. On a cache hit `observeCached` reads 16 bytes to produce `magic`; if the
   Lead would rather store magic in the index, that is a one-field change.
3. The unreadable-root test self-skips when the permission drop has no
   effect (e.g. running as root); symlink test self-skips if the FS refuses
   symlink creation, as instructed.
4. Compile-order trivia: a KDoc containing the literal glob `tmp/*.partial`
   broke the build — Kotlin block comments nest, so `/*` inside KDoc opens
   a comment. Reworded; nothing else in the package is affected.
