## Files created

- `app/src/main/java/org/dhamma/gong/assets/AudioAssetManager.kt`
  Pinned API (`states`, `catalog`, `isMetered`, `refreshFromDisk`, `request`,
  `requestAll`, `scanStorage`, `TrackState`). Android-free like `AssetStore`:
  connectivity (`online`/`metered`), passphrase, and legacy scan roots are
  injected lambdas, so every path is plain-JVM testable.
  - Prepare loop: observe (`observeCached` fast path, fresh `observe` after any
    disk mutation) → `AssetResolve.next` → perform step → repeat, hard cap 8
    iterations then `Error("Could not prepare this track")`.
  - Steps: Play→Ready; Decrypt→`OpenSslSaltedAes.decryptingStream` into
    `.dec.partial`, verify size+sha+magic via `AssetResolve.verifyReady`,
    atomic-move to ready (ciphertext kept — keepEncryptedCopy);
    Download→`CdnDownloader.fetch` with progress mapped to `Downloading`,
    Complete→atomic-move partial→encrypted; Discard→quarantine
    (READY/ENCRYPTED) or delete+invalidate (PARTIAL); MoveReadyToEncrypted→
    atomic-move; Blocked→OFFLINE/NO_SPACE plain-sentence `Error`, NO_KEY→`NoKey`.
  - Single-flight: per-id claim taken *synchronously* in `request()` before the
    coroutine launches, so a duplicate request is dropped deterministically.
  - Keyless build: `refreshFromDisk` marks every non-Ready asset `NoKey`; a
    `request` that reaches the Download step with no key sets `NoKey` and never
    opens a socket; a verified ready file still becomes `Ready`.
  - `scanStorage`: depth-2 `StorageLocator` over injected legacy roots (dedupe
    by canonical path, unreadable roots skipped); verified hits are *copied*
    (stream, never move) via the store's tmp paths, then prepared with the
    network forced off — discovery can never turn into a surprise download.
- `app/src/main/java/org/dhamma/gong/assets/AudioAssets.kt`
  Double-checked-locking singleton over `applicationContext`. Supplies:
  catalog from `assets/doha_manifest.json`, `AssetStore` at
  `(getExternalFilesDir(null) ?: filesDir)/audio`, `CdnDownloader`,
  `SupervisorJob + Dispatchers.IO` scope, `BuildConfig.MEDIA_PASSPHRASE` as a
  fresh CharArray per call (wiped after use, never logged),
  ConnectivityManager online (INTERNET capability, unknown→false) / metered
  (unknown→true), legacy roots {ExternalStorageDirectory, /sdcard,
  /storage/emulated/0}.
- `app/src/main/java/org/dhamma/gong/assets/DownloadedSlotRegistrar.kt`
  Collects `manager.states` mapped to the *set* of ready files with
  `distinctUntilChanged` (progress ticks never touch the DB; StateFlow replay
  covers "once at start"). For each ready asset: `DohaPackMapper.parseSlot`
  on the filename; writes `MediaSlotEntity(slot, Uri.fromFile(...),
  filename, source=downloaded)` only when the slot has NO row. Never replaces
  an existing row of any source.

## Notes for the Lead

- `AudioAssetManager`'s constructor differs from the plan's sketch (lambdas
  `online`/`metered`/`legacyRoots` instead of one `networkAllowed`) — allowed
  by the B1 brief ("constructor is yours to design"); the pinned surface B2
  codes against (`AudioAssets.get` + public members) is exact.
- Decrypt failure on a *verified* ciphertext (wrong key / bad padding) is
  terminal `Error`, not a retry loop — retrying an identical decrypt cannot
  end differently.
- No `Log.*` calls in the manager at all (keeps it JVM-pure; nothing secret
  or otherwise is logged by B1 code).
